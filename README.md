# 쿠키런 보물 랜덤 뽑기

쿠키런 for Kakao 보물 중에서 3개를 랜덤으로 뽑는 페이지예요.
달리기(인게임)에 효과가 없는 보물은 빠져 있어요:
출석 보상(출석 시 크리스탈·코인 등), 추출 시 마법가루, 코인으로 판매, 경험치 물약, 능력 정보가 없는 보물.
한국어 능력 설명이 없는 보물(영어 이름만 있는 중복 항목 등)도 빠져 있어요.

## 기능

- **보물 3개 뽑기** — 3칸을 한 번에 새로 뽑아요. 세 칸끼리는 절대 안 겹쳐요.
- **칸별 리롤** — 각 칸의 `리롤` 버튼으로 하나씩 다시 뽑아요. 방금 있던 보물은 다시 안 나와요.
- **중복 없이 뽑기** (옵션) — 켜 두면 한 번 나온 보물(리롤로 넘긴 것 포함)은 `초기화` 전까지 다시 안 나와요.
- **리롤 횟수** — `횟수 지정`(최대 N회, 숫자 직접 입력) · `무제한` · `리롤 불가` 중에서 골라요.
  리롤 횟수는 `새로 뽑기`를 눌러도 이어서 세고(새로 뽑기는 리롤로 안 쳐요), `초기화`를 눌러야 0회로 돌아가요. 남은 횟수도 보여 줘요.
- **필터** — 등급 S/A/B/C, 진화/미진화, 종류. 칩을 더블클릭하면 그것만 선택돼요.
- 진화 전·후 같은 보물 함께 안 나오게, 뽑기 연출 끄기, 단축키 `R`(새로 뽑기) · `1` `2` `3`(그 칸 리롤).
- 필터·옵션·뽑은 결과는 브라우저에 저장돼서 새로고침해도 그대로예요.

## GitHub Pages로 올리기 (처음 한 번)

1. GitHub에서 새 저장소를 만들고 이 폴더 내용을 그대로 올려요.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔요.
3. **Actions** 탭 → **배포 · 보물 데이터 갱신** → **Run workflow**를 한 번 눌러요.
   1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열려요.

그다음부터는 main에 올릴 때마다 자동으로 반영돼요.
`index.html`을 더블클릭해서 바로 열어도 동작해요 (서버 필요 없음).

## 새 보물이 나왔을 때

| 방법 | 하는 일 |
| --- | --- |
| **자동 (기본)** | 매일 아침 6시 반쯤 쿠키런HUB 도감을 확인해서, 바뀐 게 있으면 알아서 커밋하고 사이트에 반영해요. |
| **지금 바로** | 저장소 **Actions → 배포 · 보물 데이터 갱신 → Run workflow** |
| **내 컴퓨터에서** | `python3 tools/update_data.py` 실행 → 커밋 · 푸시 |

- 새로 생긴 · 빠진 · 바뀐 보물을 알려 줘요 (Actions 실행 화면의 요약에도 나와요). 바뀐 게 없으면 파일을 건드리지 않아요.
- 달리기에 효과가 없는 보물은 능력 설명을 보고 알아서 걸러요. 새로 나온 것도 자동으로 빠져요.
  코인·경험치 보너스만 있는 보물까지 빼려면 `tools/update_data.py`에서 `EXCLUDE_BONUS_ONLY = True`로 바꾸면 돼요.
- 새 보물 그림만 받고, 목록에서 빠진 보물 그림은 지워요.
- 배포할 때 파일 주소에 버전 번호를 붙여서, 갱신 직후에도 방문자 브라우저가 옛 데이터를 쓰지 않아요.
  내 컴퓨터에서 열어 볼 때 예전 내용이 보이면 `Ctrl+Shift+R`(맥은 `Cmd+Shift+R`)로 새로고침하세요.
- 저장소에 60일 동안 아무 변화가 없으면 GitHub가 매일 자동 실행을 멈춰요. 그럴 땐 Actions 탭에서 다시 켜면 돼요.

## 어디를 고치면 되나요

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 뽑는 개수, 종류 이름, 처음 옵션 (리롤 횟수 포함) | `js/config.js` |
| 빼는 보물 (인게임 효과 없는 보물 · 코인/경험치 보너스만 · 종류째 · 특정 보물 id) | `tools/update_data.py` 맨 위 "설정" |
| 색 · 크기 같은 모양 | `css/style.css` |
| 뽑기 동작 | `js/app.js` |
| 보물 목록 | `data/treasures.js` — 자동 생성이라 직접 고치지 않아요 |

빼는 보물 설정을 바꿨다면 그냥 올리면 자동으로 데이터를 다시 만들어요 (내 컴퓨터에서는 `python3 tools/update_data.py`).
보물 id는 `data/treasures.js`에서 이름으로 찾으면 줄 맨 앞에 있어요.

## 파일 구성

```
index.html                    페이지
css/style.css                 디자인
js/config.js                  설정
js/app.js                     동작
data/treasures.js             보물 목록 (자동 생성 · 보물 하나가 한 줄)
images/treasures/             보물 그림 (자동 생성)
images/ui/                    등급 배지
tools/update_data.py          데이터 갱신 스크립트 (파이썬 3.9+, 추가 설치 없음)
.github/workflows/pages.yml   배포 + 매일 자동 갱신
```
